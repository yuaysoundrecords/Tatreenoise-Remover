ติดตั้ง Tatree แล้ว

เปิด DAW แล้วสแกนปลั๊กอินใหม่ ค้นหา Tatree หากยังขึ้นคำเตือนความปลอดภัย ให้ปิด DAW ก่อน แล้วตรวจสถานะตัวติดตั้งใน System Settings → Privacy & Security

การอนุญาตตัวติดตั้งที่ยังไม่ได้ notarize ไม่ได้ยืนยันว่าทุกปลั๊กอินภายในจะผ่าน Gatekeeper ตัวติดตั้งไม่ปิด Gatekeeper และไม่ลบ quarantine ให้เอง หาก macOS ยังบล็อกปลั๊กอิน ให้ใช้รุ่น Developer ID ที่ notarize แล้ว หรือบิลด์จากซอร์สบนเครื่องของคุณ
