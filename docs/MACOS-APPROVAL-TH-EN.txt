Mac installation
1. Close your DAW and plug-in scanners.
2. For the Setup download, open the .pkg installer.
   For the ZIP download, copy .vst3 to ~/Library/Audio/Plug-Ins/VST3
   and .component to ~/Library/Audio/Plug-Ins/Components.
   Create missing folders. Choose one method to avoid duplicate installations.
3. If macOS blocks the plug-in, try System Settings > Privacy & Security approval.
4. If it still will not open and you trust the download source, double-click
   1.Mac กดอันนี้ก่อนครับ - Mac Start with This!.command
   Use it before opening the DAW, but only AFTER installing the plug-in.
5. Review the target paths. Type YES to confirm, or Enter to cancel.
   Enter your Mac password if prompted; typing is hidden.
6. After Done, open your DAW and rescan Tatree.
   If an error appears, stop and contact the developer; success is not confirmed.

The helper removes quarantine only from the listed Tatree AU/VST3 bundles, not Standalone.
It does not disable Gatekeeper globally and is not Developer ID signing or Apple notarization.
macOS may block the helper itself. Approve only trusted files in Privacy & Security.
A valid ad-hoc signature checks file integrity, not publisher identity.
Compatibility depends on your macOS version and DAW.

Quick use
Insert Tatree on a vocal track. Listen at a low level and adjust Noise, De-esser and Breath.
LISTEN auditions the removed signal; reduce processing if it removes too much of the vocal.
Auto Gain helps stage vocal levels before cleanup; it is not a limiter.
Set Input/Output levels and compare with BYPASS.
