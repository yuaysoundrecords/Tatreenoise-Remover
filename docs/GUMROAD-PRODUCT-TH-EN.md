ติดตั้ง Windows
1. ปิด DAW แล้วแตก ZIP
2. เปิดไฟล์ Setup.exe แล้วติดตั้งตามหน้าจอ ใช้สิทธิ์ผู้ดูแลระบบ
3. เปิด DAW สแกน VST3 ใหม่ แล้วหา Tatree Noise Remover 2 ในชื่อผู้ผลิต Yuay Sound Records

ติดตั้ง Mac
1. ปิด DAW แล้วแตก ZIP
2. เปิดไฟล์ .pkg เพื่อติดตั้ง AU, VST3 และ Standalone
3. หาก macOS บล็อก ให้ลองอนุญาตใน System Settings > Privacy & Security
4. หากยังเปิดไม่ได้ และเชื่อถือแหล่งดาวน์โหลดนี้ ให้เปิด
   1.Mac กดอันนี้ก่อนครับ - Mac Start with This!.command
   ใช้หลังติดตั้งปลั๊กอินและก่อนเปิด DAW อ่านเส้นทางแล้วพิมพ์ YES เพื่อยืนยัน
   ใส่รหัสผ่าน Mac หากระบบถาม ขณะพิมพ์จะไม่แสดงตัวอักษร
5. เมื่อขึ้น Done ให้เปิด DAW แล้วสแกนปลั๊กอินใหม่

Mac ชุดนี้ยังไม่ได้เซ็น Developer ID หรือ notarize กับ Apple จึงอาจมีคำเตือน
ตัวช่วยถอด quarantine เฉพาะ Tatree AU/VST3 ที่แสดง ไม่ปิด Gatekeeper ทั้งเครื่อง
macOS อาจเตือนตัวช่วยเองด้วย อนุญาตเฉพาะไฟล์ที่เชื่อถือ
Windows Setup ยังไม่มีลายเซ็น Authenticode เช่นกัน
อ่าน INSTALL-TH-EN.txt ในชุดดาวน์โหลดก่อนติดตั้ง รวมวิธีย้าย Tatree เดิมเพื่อไม่ให้ซ้ำ

Tatree Noise Remover 2 — Free for Windows and Mac

Cleaning up a vocal with fan noise, hiss, sharp sibilance or distracting breaths?
Adjust Noise, De-esser and Breath separately. LISTEN lets you hear what is being removed.
If it takes too much of the vocal with it, ease back the relevant control.

- Noise Reduction for background noise
- De-esser for excessive sibilance
- Breath Reduction for low-level breaths
- Low-cut Filter
- Pre-chain vocal Auto Gain with Input / Output Gain
- BYPASS for comparison and optional Motion FX

All features are free. No time limit, activation key or account required to use the plug-in.
Optional support: TIP / KO-FI in the top-right corner or https://ko-fi.com/yuaylooper.
Tipping does not unlock or change any feature.

Downloads
Windows 64-bit: Tatree-2.1.3-Windows-Setup.zip — Setup and installation guide
Mac Intel / Apple Silicon: Tatree-2.1.3-macOS-Setup.zip — .pkg installer, Mac helper and guide
Both downloads contain the same version. Choose your operating system.

Windows installation
1. Close your DAW and extract the ZIP.
2. Run Setup.exe and follow the installer. Administrator access is required.
3. Open your DAW, rescan VST3, and look for Tatree Noise Remover 2 by Yuay Sound Records.

Mac installation
1. Close your DAW and extract the ZIP.
2. Open the .pkg installer to install AU, VST3 and Standalone.
3. If macOS blocks the plug-in, try System Settings > Privacy & Security approval.
4. If it still will not open and you trust the download source, run
   1.Mac กดอันนี้ก่อนครับ - Mac Start with This!.command
   Use it AFTER installation and before opening the DAW. Review the paths and type YES.
   Enter your Mac password if prompted; typing is hidden.
5. After Done, open your DAW and rescan the plug-in.

The Mac package is not Developer ID signed or notarized by Apple; warnings may appear.
The optional helper removes quarantine only from the listed Tatree AU/VST3 bundles.
It does not disable Gatekeeper globally, and macOS may block the helper itself.
Approve only trusted files. Windows Setup is not Authenticode-signed either.
Read INSTALL-TH-EN.txt in the download before installing, including the steps for avoiding
duplicate Tatree installations.

Getting started
Insert Tatree on a vocal track and listen at a low level while adjusting the controls.
Use LISTEN to check the removed signal, then turn LISTEN off before exporting.
Auto Gain helps stage average vocal levels; it is not a limiter and cannot repair recorded clipping.
Set Input / Output levels and compare with BYPASS.
