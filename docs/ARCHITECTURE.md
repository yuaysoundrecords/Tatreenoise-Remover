# Tatree 2 architecture

A new native JUCE 8.0.8 C++17 effect. No runtime browser, remote API, account, model download or cloud audio processing.

- `Denoiser.h`: fixed-buffer 1024-point real FFT, 256-sample hop, square-root Hann WOLA. Two-window smoothed minimum-statistics noise tracking, conservative startup, speech-presence-gated noise adaptation and suppression weight, bounded spectral-subtraction gain, temporal/frequency smoothing, sample-rate-scaled coefficients. The initial profile is estimated automatically; very quiet consonants can still be attenuated at aggressive settings.
- `PluginProcessor`: mono/stereo, input trim, optional stereo-linked pre-chain Auto Gain, 75 Hz low-cut, denoiser, stereo-linked TPT split-band de-esser with matched RMS detectors, duration-gated low-level unvoiced attenuation with rapid voiced recovery, and output trim. All callback buffers and filters are prepared in advance. Parameters smooth over 25 ms; bypass/listen/filter transitions over 15 ms. Host reports fixed 1024-sample latency. Bypass and removed-signal audition use aligned dry audio.
- `Metering`: lock-free scalar atomics bridge audio/UI. IN/OUT are peak with 200 ms decay, UI peak markers hold for one second; GR is block energy attenuation against the aligned dry signal, clamped to 0–40 dB and displayed on a 0–24 dB scale. GR rows duplicate a stereo-linked aggregate rather than representing independent channel GR. Noise/de-ess detector readings separately drive motion. Raw input, conditioned input and output hot events are latched until consumed. IN is post input/Auto Gain; output is post output trim. Bypass uses a separate raw 1024-sample delay; delta uses the conditioned aligned reference.
- `MotionState`: timer-thread state machine at 30 Hz. Input hot (800 ms hold) > bypass > delta listen > de-esser > breath > noise > idle. Filter/control-touch feedback is separate from detector activity. Noise and de-ess strength use 45 ms attack and 220 ms release to avoid chatter. Motion preference disables transforms, preserving visual status. Three pre-rendered full-colour cutouts: raised finger, de-esser hush, and input-hot surprise. Rotation/lift add motion; no live generation. A callback counter decays meters and motion to idle when the host stops delivering audio.
- `PluginEditor`: resizable 1080×860 native component, 80–150%; cream paper/cobalt typography, original-identity colour photo collage, native keyboard-accessible knobs with exact editable percentages, readable stereo meters and peak warning. Speech banners use bold Noto Sans Thai and actual glyph-outline bounds, right-aligned and rotated as a unit. Compiled assets/fonts require no network at runtime.
- `TatreeOffline`: offline mono/stereo WAV processor. Streams fixed 512-sample blocks and trims declared latency.
- `TatreeTests`: signal reconstruction, denoising, band-specific attenuation, bypass alignment, state restore, peak latch, rate/block size safety, motion priority/hold/reduced-motion checks.
- `TatreeRender`: native UI integration harness and evidence capture with DSP-driven inputs.

## Input levelling and quote feedback (2.0.3)

`AutoGain.h`: optional pre-chain stereo-linked vocal levelling to -18 dBFS active RMS, correction bounded -24/+12 dB. Analysis windows are 20 ms; 400 ms RMS / 800 ms peak memory, 350 ms downward and 1.5 s upward smoothing. Gain slew is limited to -12/+3 dB/s and has a 0.15 dB deadband. An absolute -48 dBFS and relative -18 dB activity gate holds the gain/reference through silence and low breaths; a sustained quieter section is accepted after 3 s. Disable returns to unity over 50 ms. Peak-aware requested boost is capped for -3 dBFS headroom; no lookahead/limiter is added. Input/output trims retain 25 ms smoothing and all gain preferences persist/automate.

`SpeechFeedback.h` is a separate UI-thread 3 s interaction latch. Input/output movement maps to the Peak quote, ess/noise movement to their quotes, and Auto Gain ON **and OFF** clicks to the Auto quote. Parameter changes are also observed to cover keyboard edits/automation. Opening the editor snapshots current values without triggering speech. DSP detectors continue driving actual meters and MotionState. Four long captions share a fitted bold font and semantic two-line breaks; outline-based padding is 23 px horizontally / 12 px vertically. Idle retains the short title.

## Compatibility

New plugin code `Ttr2`, manufacturer `Yuay`, bundle `net.yuaysoundrecords.tatree2`. Does not impersonate old binary IDs. Formats: VST3 + Standalone everywhere supported by JUCE, AU on macOS. No promise of compatibility with v1 project states.
